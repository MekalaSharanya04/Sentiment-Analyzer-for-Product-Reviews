# Dataset

## Description
This folder contains the dataset used for the **Sentiment Analyzer for Product Reviews** project.

## Dataset Name
Amazon Product Reviews Dataset

## Source
Kaggle - Amazon Product Reviews Dataset

## Dataset Contents
The dataset contains customer product reviews and their corresponding ratings. The review text is used to train the sentiment analysis model.

## Sentiment Labels
The ratings will be converted into sentiment categories:

- Ratings 1–2 → Negative
- Rating 3 → Neutral
- Ratings 4–5 → Positive

## Purpose
The dataset is used for:
- Data exploration
- Text preprocessing
- Feature extraction using TF-IDF
- Training and testing Machine Learning models

**Dataset File:** `amazon_reviews.csv`
