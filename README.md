# Sentiment Analyzer for Product Reviews

## Project Overview
This project aims to analyze customer product reviews using Machine Learning and Natural Language Processing (NLP). It classifies reviews into Positive, Negative, or Neutral sentiments.

## Objectives
- Analyze customer opinions.
- Classify product reviews automatically.
- Help businesses understand customer feedback.

## Features (Planned)
- Review preprocessing
- Sentiment prediction
- Machine Learning model training
- Streamlit web application
