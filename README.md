# Sentiment Analyzer for Product Reviews

## Project Overview
This project uses Machine Learning and Natural Language Processing (NLP) to analyze customer product reviews and classify them as Positive, Negative, or Neutral.

## Objectives
- Analyze customer reviews automatically.
- Predict Positive, Negative, or Neutral sentiment.
- Reduce manual effort in review analysis.
- Help businesses understand customer feedback.

## Features
- Text preprocessing
- Sentiment prediction
- Confidence score
- Simple Streamlit web application

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Matplotlib
- Streamlit
- Git
- GitHub
