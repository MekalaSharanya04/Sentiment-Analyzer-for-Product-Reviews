# Literature Review

Sentiment Analysis is a technique in Natural Language Processing (NLP) that is used to identify whether a product review is Positive, Negative, or Neutral.

Many researchers have used Machine Learning algorithms such as:
- Naive Bayes
- Logistic Regression
- Support Vector Machine (SVM)

Before training the model, the review text is cleaned and converted into numerical form using **TF-IDF Vectorization**.

This project uses these techniques to build a simple and accurate sentiment analysis system. It also displays the confidence score of the predicted result.
