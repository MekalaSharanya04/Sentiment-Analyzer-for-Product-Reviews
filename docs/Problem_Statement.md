# Problem Statement

## Introduction
Customer reviews play a vital role in helping businesses understand customer satisfaction. On e-commerce platforms such as Amazon and Flipkart, thousands of reviews are posted every day. Reading and analyzing each review manually is time-consuming and inefficient.

## Problem
Businesses need an automated system that can quickly determine whether a customer's review expresses a positive, negative, or neutral opinion.

## Proposed Solution
This project aims to develop a Sentiment Analyzer using Machine Learning and Natural Language Processing (NLP). The system will automatically classify product reviews into sentiment categories, helping businesses make data-driven decisions and improve customer satisfaction.

## Objectives
- Collect product review data.
- Preprocess review text.
- Train a Machine Learning model.
- Predict sentiment of new reviews.
- Display results through a simple web application.

## Expected Outcome
A web-based application that accepts a product review as input and predicts its sentiment as Positive, Negative, or Neutral.
