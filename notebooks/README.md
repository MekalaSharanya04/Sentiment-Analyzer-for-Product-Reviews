# Notebooks

This folder contains the Jupyter Notebooks used for developing the Sentiment Analyzer for Product Reviews project.

## Notebooks

### Week2_Data_Preprocessing.ipynb
- Dataset loading
- Data exploration
- Missing value and duplicate checking
- Text cleaning
- Stop-word removal
- Tokenization
- Lemmatization
- TF-IDF feature extraction

### Week2_Linear_Regression.ipynb
- Features and labels
- Train/test split
- Linear Regression
- Predictions
- Model evaluation using MAE, MSE, RMSE and R² score

These notebooks document the step-by-step development and learning process of the project.
